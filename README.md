# Flexozy Keygate

ระบบแจกคีย์ผ่าน Discord — ใช้ธีมขาวดำ/เงาแข็งของ Flexozy เป็นฐาน, ตัดระบบเช็คสลิปออกทั้งหมด (เหลือเฉพาะ **ล็อกอิน Discord**) แล้วรวมระบบ **keygate-v3** เข้ามาพร้อมของใหม่

## สิ่งที่ได้

| หมวด | รายละเอียด |
|---|---|
| ล็อกอิน | Discord OAuth (Redirect เดิม `/api/auth/callback` ใช้ต่อได้) · **เพิ่มผู้ใช้เข้าเซิร์ฟเวอร์อัตโนมัติ** ด้วยบอท (`guilds.join`) · ใส่ยศให้อัตโนมัติได้ |
| หน้าแจกคีย์ | 3 ขั้นตอน (ลิงก์ → Discord → captcha) + รับคีย์ · ไทย/อังกฤษ · นับถอยหลังอายุคีย์ |
| ตกแต่ง | 4 สไตล์การ์ด (Brutal / Glass / Outline / Terminal) · สีเน้น · 6 ฟอนต์ · มุมโค้ง · **พื้นหลังรูป/GIF** (ทำขาวดำ/เบลอ/ปรับความมืดได้) · **เพลง** (อัปโหลด mp3/ogg/wav/m4a หรือลิงก์ mp3 / YouTube) · เอฟเฟกต์ (หิมะ/ดาว/ฝน/Matrix/ฟอง) · โลโก้ แบนเนอร์ ไอคอนปุ่มเอง · แก้ข้อความทุกปุ่ม · **พรีวิวสด** |
| ตกแต่งทั้งเว็บ | แอดมินตั้งโลโก้ พื้นหลัง GIF เพลง เอฟเฟกต์ แถบประกาศ ได้จากหน้าเว็บ ไม่ต้อง redeploy |
| แอดมิน | แก้/ตกแต่ง **หน้าของคนอื่น** ได้ทุกอย่าง · จัดการคีย์ (สร้างทีละหลายอัน/ต่ออายุ/ยกเลิก/ลบ) · อนุมัติ-ถอนผู้สร้าง · เปิด/ปิด/ลบหน้า · แบน · เพิ่ม/ถอนแอดมิน (เจ้าของ) · ตั้งค่าความปลอดภัย · ดู log |
| Roblox / สคริปต์ | `GET /api/verify?key=…` + ตัวอย่าง `roblox/KeyTimer.lua` · `POST /api/bot` สำหรับบอทของคุณ |
| ฐานข้อมูล | Upstash Redis / Vercel KV — หรือไม่ตั้งอะไรเลย = เก็บลงไฟล์ `.data` (เฉพาะ VPS/เครื่องตัวเอง) · **อ่านข้อมูลเดิมจาก keygate-v3 ได้** |

## ตั้งค่า (ทำตามลำดับ)

1. **Discord Developer Portal → New Application**
   - OAuth2 → คัดลอก `Client ID` / `Client Secret`
   - OAuth2 → Redirects → เพิ่ม `https://โดเมนคุณ/api/auth/callback` (ตรวจค่าที่ถูกต้องได้ที่ `/api/health` ช่อง `redirectUri`)
2. **เพิ่มคนเข้าเซิร์ฟเวอร์ตอนล็อกอิน** (ไม่บังคับ แต่ได้ฟีเจอร์ครบ)
   - Developer Portal → Bot → Reset Token → ใส่ใน `DISCORD_BOT_TOKEN`
   - เชิญบอทเข้าเซิร์ฟเวอร์ (OAuth2 → URL Generator → scope `bot` → สิทธิ์ **Create Instant Invite**; ถ้าจะให้ยศอัตโนมัติเพิ่ม **Manage Roles** และยศบอทต้องอยู่เหนือยศที่จะให้)
   - ตั้ง Guild ID ใน `DISCORD_GUILD_ID` หรือที่หน้า **แอดมิน → ตั้งค่าเว็บ** แล้วกด "บันทึก + ทดสอบบอท"
3. **ฐานข้อมูล**: สร้าง Upstash Redis (ฟรี) แล้วใส่ `KV_REST_API_URL` / `KV_REST_API_TOKEN` (หรือเชื่อมผ่าน Vercel Marketplace)
4. ใส่ env ตาม `.env.example` — อย่างน้อย `SESSION_SECRET`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `ADMIN_IDS`
5. Deploy (Vercel: อัปโหลดโฟลเดอร์/GitHub แล้ว Deploy) หรือรันเอง `npm i && npm run build && npm start`
6. เปิด `/api/health` ดูว่าทุกอย่างเขียว แล้วล็อกอินด้วยบัญชีใน `ADMIN_IDS`

## วิธีใช้

- **แอดมิน**: เมนู *แอดมิน → หน้า & ผู้สร้าง* ใส่ Discord ID + slug → อนุมัติ → ระบบเปิดตัวแก้ไขให้ทันที (หรือกด "แก้ไข/ตกแต่ง" ที่หน้าใครก็ได้)
- **ผู้สร้าง**: เมนู *สร้างหน้าแจกคีย์* → แท็บ ทั่วไป / สไตล์ / พื้นหลัง & เพลง / ลิงก์ / คีย์ / สถิติ → บันทึก → ส่งลิงก์ `/getkey/slug`
- **GIF**: อัปโหลดได้ถึง 2.8MB — ใหญ่กว่านั้นวางลิงก์ตรง `.gif` (Discord CDN / Giphy / Tenor) · **เพลง**: อัปโหลดได้ถึง 4.2MB หรือวางลิงก์ mp3 / YouTube (เบราว์เซอร์บังคับให้ผู้ชมแตะหน้าจอก่อนจึงเล่นเสียงได้ — มีปุ่มเพลงลอยให้เปิด/ปิด/ปรับเสียง)

## ระบบกัน bypass (แอดมินเปิด/ปิด/ปรับได้ที่ *ความปลอดภัย*)

ทั้งหมดตรวจ **ฝั่งเซิร์ฟเวอร์** (โค้ดฝั่งเบราว์เซอร์ผู้เล่นปลอมได้เสมอ):

1. สถานะขั้นตอน + ตัวจับเวลา อยู่ที่เซิร์ฟเวอร์ — กดก่อนเวลา/ข้ามขั้น = ถูกปฏิเสธและนับ strike
2. **Proof-of-Work** — เบราว์เซอร์ต้องคำนวณ hash (แก้ระหว่างรอ ผู้ใช้ไม่รู้สึก) ผูกกับผู้ใช้+ขั้นตอน ใช้ซ้ำไม่ได้ → สคริปต์ยิงรัวๆ ช้าลงมาก
3. **ตรวจว่าอยู่ในเซิร์ฟเวอร์ Discord จริง** ด้วยบอท ก่อนขั้น 3 และตอนรับคีย์ (ขั้น Discord ถูกตรวจจริง ไม่ใช่แค่กดผ่าน)
4. Cloudflare Turnstile (ถ้าตั้ง) ทั้งหน้าด่านแรกและขั้น captcha
5. บล็อก User-Agent สคริปต์ / ตรวจ Origin + `Sec-Fetch-Site` (กัน CSRF และคำขอข้ามเว็บ)
6. ผูกขั้นตอนกับเบราว์เซอร์ (UA) และ (เลือกได้) IP ตอนเริ่ม
7. อายุบัญชี Discord ขั้นต่ำ (ค่าเริ่มต้น 3 วัน) · จำกัดคีย์ต่อ IP ต่อวัน (ปิดไว้ก่อน เพราะเน็ตมือถือไทยแชร์ IP)
8. Rate limit ต่อผู้ใช้/IP · ระบบ **strike** ทำผิดซ้ำ → บล็อกอัตโนมัติ 1 ชม. + บันทึกใน log ให้แอดมินแบน/ปลดได้

ข้อจำกัดที่ต้องรู้: ไม่มีระบบฝั่งเว็บใดกัน bypass ได้ 100% — โดยเฉพาะ "ขั้นไปกดติดตาม YouTube" ที่เว็บตรวจไม่ได้ว่าทำจริงไหม สิ่งที่ระบบนี้ทำคือ *เพิ่มต้นทุนของการโกงให้สูง* และ *ตรวจสิ่งที่ตรวจได้จริง* (การเป็นสมาชิก Discord, เวลา, ความเป็นเบราว์เซอร์จริง)

## โครงสร้าง

```
app/(main)/        หน้าเว็บหลัก (/, /create, /admin) — ใช้ nav และธีม Flexozy

app/globals.css    ธีมขาวดำเดิม     app/ui.css  ส่วนเสริมใหม่
lib/api/           auth · pub · gate · creator · admin · bot

lib/security.js    PoW / rate limit / strike / Turnstile

roblox/KeyTimer.lua
```

## ย้ายจากของเดิม

- ใช้ฐานข้อมูล Upstash/KV เดียวกับ keygate-v3 ได้เลย (คีย์/หน้า/ผู้สร้างเดิมอ่านได้) — รูปที่อัปโหลดไว้ในรูปแบบเก่าก็ยังแสดง
- ตัวแปร `BASE_URL` เดิมยังใช้ได้ (หรือใช้ `SITE_URL`) · Cookie ล็อกอินเปลี่ยนชื่อ ผู้ใช้ต้องล็อกอินใหม่ 1 ครั้ง
- ลบแล้ว: เช็คสลิป / สร้างสลิป / API key / PromptPay / เอกสาร API เดิมของ Flexozy ทั้งหมด

## ข้อควรระวังตอน deploy

- บน **Vercel ต้องต่อ KV/Upstash** — ถ้าไม่ต่อ ข้อมูลจะหายเมื่อฟังก์ชันรีสตาร์ท (หน้า `/api/health` จะเตือน)
- หน้าเว็บเป็น server-rendered ทั้งหมด (`force-dynamic`) เพราะอ่านการตั้งค่าเว็บจาก KV
