# Flexozy Hub — ร้านขายของดิจิทัล (Next.js + Postgres) รันบน Vercel

เว็บร้านค้าที่ทำตามหน้าตา/เนื้อหาแบบร้านค้าดิจิทัล พร้อมระบบหลังบ้านใช้งานจริง

## ระบบที่มี
- หน้าแรก (สถิติจริงจากฐานข้อมูล), หมวดหมู่, ร้านค้า, หน้าสินค้า, ค้นหา (Ctrl/⌘+K), นโยบายความเป็นส่วนตัว
- สมัครสมาชิก / เข้าสู่ระบบ (bcrypt + session cookie HttpOnly, กันเดารหัสผ่าน, กัน CSRF)
- กระเป๋าเงิน: เติมเงินผ่าน **TrueMoney Gift (วางลิงก์ซอง → ระบบรับซองเข้าเบอร์ร้านอัตโนมัติ)** (ปิดระบบเติมเงินธนาคาร/สลิปแล้ว)
- ซื้อสินค้า: หักเงิน + ส่งคีย์/โค้ดจากสต็อกทันทีในธุรกรรมเดียว (ซื้อพร้อมกันไม่ติดลบ ไม่ส่งคีย์ซ้ำ)
- โค้ดส่วนลด (% หรือเป็นบาท, จำกัดครั้ง, วันหมดอายุ), สินค้าสุ่ม, ประวัติออเดอร์ (เห็นคีย์ย้อนหลัง)
- แบนเนอร์ขอความยินยอมคุกกี้ (ยอมรับทั้งหมด / เฉพาะที่จำเป็น / ตั้งค่า) จำค่าไว้ 1 ปี และเปิดแก้ได้จากปุ่ม “เปลี่ยนการตั้งค่าคุกกี้” ในหน้านโยบายความเป็นส่วนตัว
- ป๊อปอัปประกาศร้าน (ตั้งได้สูงสุด 5 ประกาศที่ `/admin` → ตั้งค่า, ปิดแล้วไม่เด้งซ้ำจนกว่าจะแก้ประกาศ) — ต้นฉบับเปิดระบบไว้แต่ยังไม่มีประกาศ จึงเริ่มต้นเป็นว่าง
- วิดเจ็ต Discord ท้ายเว็บขนาด 350×320 (Server ID เริ่มต้นคือเซิร์ฟเวอร์ Flexozy Hub แก้ได้ที่ `/admin` → ตั้งค่า; ต้องเปิด Server Widget ใน Discord ด้วย)
- หลังบ้าน `/admin`: ภาพรวม, สินค้า, **สต็อก (วางคีย์ทีละบรรทัด)**, หมวดหมู่, เติมเงิน, ออเดอร์, สมาชิก (ปรับยอด/ระงับ/ตั้งแอดมิน), โค้ดส่วนลด, ตั้งค่าร้าน

## ฟีเจอร์เพิ่มใหม่ (v14.13) — สินค้าแบบ “คีย์อัตโนมัติ”
กดซื้อแล้วระบบ **สุ่มคีย์ให้ทันที** รูปแบบ `FLEXOZY-XXXX-XXXX-XXXX` (12 ตัวสุ่ม ตัดตัวสับสน 0/O/1/I) ไม่ต้องเติมสต็อก ซื้อได้ไม่จำกัด
- **ตั้งค่าต่อแพ็ก** (`/admin` → สินค้า → ประเภท “คีย์อัตโนมัติ”): คำนำหน้าคีย์, อายุ (นาที / ชั่วโมง / วัน / ตลอดชีพ), เริ่มนับเวลา (เมื่อใช้งานครั้งแรก หรือ ตั้งแต่ซื้อ), ผูกกับ 1 เครื่อง (HWID) หรือไม่
- **ตรวจคีย์ได้ทุกระบบ**: API สาธารณะ (เปิด CORS) ให้สคริปต์/บอท/โปรแกรม/เว็บเรียกเช็ก
  - `GET /api/keys/verify?key=FLEXOZY-XXXX-XXXX-XXXX&hwid=เครื่อง` หรือ `POST` JSON `{"key","hwid"}`
  - ผลลัพธ์ `valid: true/false`, `code` (OK · UNUSED · NOT_FOUND · BAD_FORMAT · EXPIRED · REVOKED · HWID_REQUIRED · HWID_MISMATCH · RATE_LIMITED), `expires_at`, `remaining_seconds`
  - `&check=1` ดูสถานะเฉยๆ (ไม่เริ่มนับเวลา) · `&format=text` ได้ผลสั้นๆ เช่น `VALID|LIFETIME`
  - ตัวอย่างโค้ด Lua / Python / JS / PowerShell / curl อยู่ที่ `/admin` → แท็บ “คีย์” → “วิธีเชื่อมระบบตรวจคีย์”
  - กันเดาคีย์: ตรวจผิดเกิน 30 ครั้ง/10 นาที ต่อ IP จะถูกชะลอ
- **จัดการคีย์** (`/admin` → คีย์): ค้นหา, ระงับ/ปลดระงับ, ต่อเวลา, รีเซ็ตเครื่อง, ลบ, สร้างคีย์เอง (แจก/ทดสอบ)
- ลูกค้าเห็นคีย์ + สถานะ (ยังไม่เริ่มใช้ / เหลือกี่วัน / หมดอายุ) ที่ บัญชีของฉัน → ประวัติการสั่งซื้อ

## ฟีเจอร์เพิ่มใหม่ (v14.14) — ผูกเครื่องอัตโนมัติ + โปรไฟล์ Roblox
- **ผูก HWID อัตโนมัติ**: ครั้งแรกที่สคริปต์ส่ง `hwid` มาตรวจคีย์ ระบบจำเครื่องนั้นไว้เอง (แพ็กที่เปิด “ผูกเครื่อง” เครื่องอื่นจะใช้ไม่ได้ — `HWID_MISMATCH`) แอดมินกด “รีเซ็ตเครื่อง” เพื่อให้ผูกใหม่ได้
- **โปรไฟล์ Roblox**: ส่ง `roblox_id` (`LocalPlayer.UserId`) และ/หรือ `roblox_name` (`LocalPlayer.Name`) มาพร้อมคีย์ ระบบดึงชื่อ / ชื่อที่แสดง / รูปจาก Roblox มาเก็บ แสดงในหลังบ้าน (แท็บ “คีย์”) และหน้าลูกค้า (“ใช้งานโดย …”) พร้อมลิงก์เปิดโปรไฟล์ — ผลลัพธ์ API มี `roblox: { id, name, display_name, avatar, profile_url }` ด้วย
- ถ้า Roblox ไม่ตอบ การตรวจคีย์ไม่พัง (ใช้ชื่อที่ส่งมาแทน)
- หมายเหตุความปลอดภัย: ข้อมูล Roblox/HWID มาจากสคริปต์ฝั่งผู้ใช้ จึงปลอมได้ถ้าสคริปต์ถูกแก้ — ใช้เป็นข้อมูลประกอบ/กันแชร์คีย์แบบทั่วไป ไม่ใช่การยืนยันตัวตนที่เด็ดขาด

### ตั้งค่าล็อกอิน Discord
1. https://discord.com/developers/applications → New Application → **OAuth2**
2. **Redirects** เพิ่ม `https://flexozy.site/api/auth/discord/callback` (ต้องตรงเป๊ะ)
3. คัดลอก Client ID / Client Secret ไปใส่ Environment Variables: `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `SITE_URL=https://flexozy.site`
4. Redeploy — คอลัมน์ Discord ในตาราง `users` ถูกเพิ่มอัตโนมัติเมื่อเปิดเว็บครั้งแรก

## ขั้นตอนขึ้น Vercel
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (หรือ `npx vercel` จากโฟลเดอร์นี้)
2. Vercel → **Add New Project** → เลือก repo (Framework: Next.js ตรวจเจอเอง)
3. แท็บ **Storage** → สร้าง/เชื่อม **Neon Postgres** (ฟรี) ให้โปรเจกต์ — Vercel จะใส่ `DATABASE_URL` ให้อัตโนมัติ
   (ใช้ Postgres เจ้าอื่นก็ได้ เช่น Supabase: ใส่ connection string แบบ pooled ใน `DATABASE_URL`)
4. **Settings → Environment Variables** ใส่:

| ตัวแปร | ค่า |
|---|---|
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | แอดมินคนแรก (รหัสผ่าน ≥ 8 ตัว) |
| `TRUEMONEY_MOBILE` | เบอร์ TrueMoney ของร้าน สำหรับรับซอง |

5. กด **Deploy** — ตารางทั้งหมดถูกสร้างอัตโนมัติเมื่อเปิดเว็บครั้งแรก ไม่ต้องรันคำสั่งอะไรเพิ่ม
6. เข้าเว็บ → เข้าสู่ระบบด้วยแอดมิน → เมนูชื่อผู้ใช้ → **จัดการหลังบ้าน**

## สำคัญก่อนเปิดขายจริง
- **สต็อกเริ่มต้นเป็น 0** (ทุกสินค้าจะขึ้น “สินค้าหมด”) → ไปที่ `/admin` → สินค้า/สต็อก → กด “จัดการ” แล้ววางคีย์/โค้ดจริงทีละบรรทัด
  - ต้องการดูหน้าตาเว็บก่อน: ตั้ง `SEED_DEMO_STOCK=1` **ก่อน deploy ครั้งแรก** จะได้คีย์ปลอม `DEMO-xxxx` (ห้ามใช้ตอนขายจริง; ถ้าฐานข้อมูลถูกสร้างไปแล้วให้ลบสต็อกจากหลังบ้าน)
- **เติมเงินอัตโนมัติ**: ซอง TrueMoney รับอัตโนมัติ ถ้า TrueMoney ไม่ตอบกลับระหว่างรับซอง รายการจะไปรอที่ `/admin` → เติมเงิน ให้แอดมินเช็กกระเป๋าแล้วกด “เติมเครดิต”
- รูปสินค้า/หมวดหมู่/โลโก้ในหลังบ้านใส่เป็น **ลิงก์** (`/uploads/...` ในโฟลเดอร์ `public/uploads` หรือ `https://...`) เพราะ Vercel เขียนไฟล์ลงดิสก์ไม่ได้
- ตัวแปรเสริม: `SEED_DEMO=0` ถ้าไม่ต้องการสินค้าตัวอย่างตอนสร้างฐานข้อมูลครั้งแรก

## เอฟเฟกต์หน้าเว็บ (FX)
- **หน้าโหลดตอนเข้าเว็บ** — `#boot` ใน `app/layout.js` (โลโก้ + วงแหวนหมุน + แถบเดิน) ถูกซ่อนโดย `components/Effects.jsx` เมื่อโหลดเสร็จ (อย่างน้อย ~0.9 วิ)
- **แถบโหลดด้านบน + หน้า skeleton ตอนเปลี่ยนหน้า** — `RouteBar` ใน `Effects.jsx`, `app/loading.js`, `app/store/loading.js`, `app/store/[id]/loading.js`
- **เอฟเฟกต์คลิก** — อนุภาค/วงแหวนตรงจุดที่กด + ริปเปิลบนปุ่ม/การ์ด/เมนู (`ClickFX`)
- **รายการโผล่ทีละตัว** — ใส่คลาส `rv` ให้องค์ประกอบใดก็ได้ (กำหนดลำดับด้วย `style={{ '--i': n }}`; ทิศทางด้วย `rv-left` / `rv-right`)
- **การ์ดสถิติ** (ผู้ใช้งาน / สินค้า / คลังสินค้า / ขายแล้ว) นับเลขขึ้นเมื่อเลื่อนมาเห็น — `components/CountUp.jsx`
- โทน/สไตล์ทั้งหมดอยู่ท้ายไฟล์ `app/globals.css` ส่วน “FX LAYER”; ผู้ใช้ที่ตั้งค่าลดแอนิเมชันในระบบ (`prefers-reduced-motion`) จะไม่เห็นเอฟเฟกต์เหล่านี้

## API Key สำหรับบอท Discord (v14.15)
`/admin` → แท็บ **API Key** → สร้างคีย์ (รูปแบบ `fxk_...`, แสดงเต็มครั้งเดียว, เก็บเป็น hash) แล้วใส่ใน `.env` ของบอทเป็น `BOT_API_SECRET=fxk_...`
บอทส่ง `Authorization: Bot <คีย์>` + `X-Discord-Id` — ไม่ต้องตั้ง env ใน Vercel / Redeploy · เพิกถอนมีผลภายใน 1 นาที · `BOT_API_SECRET` ใน env แบบเดิมยังใช้ได้

| หน้าร้านสาธารณะ (สต็อกสด) | `shop.flexozy.site/<ชื่อร้าน>` |
| API เช็คสต็อก | `flexozy.site/api/v1/shop/<ชื่อร้าน>` · รายชื่อร้าน `flexozy.site/api/v1/shop` |

**ตั้งค่า:** (1) เพิ่มโดเมน `shop.flexozy.site` ในโปรเจกต์ Vercel เดิม (2) เพิ่ม Redirect `https://shop.flexozy.site/api/auth/discord/callback` ใน Discord Developer Portal (3) ตั้ง `HUB_HOST`, `BOT_CLIENT_ID`, `SHOP_FEE_PERCENT` ตาม `.env.example` — ตารางสร้างอัตโนมัติ

**API เช็คสต็อก** `GET /api/v1/shop/<slug>` → ชื่อ รูป สีธีม ชื่อปุ่ม สินค้า (`price_baht`, `stock`, `emoji`, `in_stock`) และ `version` · ต่อท้าย `?since=<version>` ถ้าไม่มีอะไรเปลี่ยนจะได้ `{"unchanged":true}` · เปิด CORS

**ฝั่งบอท:** บอทเดียวรองรับทุกเซิร์ฟเวอร์ ถามเว็บทุก 5 วินาที (`GET /api/bot/shops`) → ตรวจว่าเจ้าของร้านเป็นเจ้าของ/มีสิทธิ์ Manage Server ในเซิร์ฟเวอร์นั้นจริง → สร้างไฟล์ `data/guilds/<guildId>.json` → โพสต์/แก้แผงร้านในห้องที่กำหนด · ซื้อ = `POST /api/bot/shop/buy` หักกระเป๋าเงินเดียวกับเว็บ โอนเข้ากระเป๋าเจ้าของร้าน (หักค่าธรรมเนียมตาม `SHOP_FEE_PERCENT`)
